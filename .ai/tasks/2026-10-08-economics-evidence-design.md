# Economics evidence design (codebase-architecture-review)

Six full councils keep returning "economics is unmeasured". This read-only design finds why, and what would fix it inside kp's limits (no new service, no paid API, no required env var, the two-minute start intact). kp already has a price book, never declared: `MTOK_PRICES` in `pipeline/jobfit/llm/base.py` plus the voice rate tables. Nearly every model call already writes an `llm_usage` row, but no council pack has ever carried telemetry. Only Google Calendar calls and the intake studio's realtime voice minutes have no record, and the voice minutes are also the one paid call with no bound. The review proposes one docs price book pinned to the code tables by tests that existing gates already run, an overlay paragraph that points the council at it (proposed, not applied), an aggregate telemetry snapshot, and a funnel fix so an unpriced sum never reads `$0.00`. It orders the work as single-branch steps, marks the ones that touch features whose Approval is waiting, and closes with six operator questions. No code changed.

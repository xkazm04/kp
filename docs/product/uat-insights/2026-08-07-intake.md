run surfaced beyond its bug list. Sources: the three per-Character L1 reports
(Tomáš — first-time team-lead requestor · Eva — eng hiring lead · Priya —
healthcare-clinic HRBP), the live L2 journal + shots, `SUMMARY.md`,
`findings.json`. Rule of this document: **no invented user needs** — every
opportunity cites a Character voice or a finding; every decline records its
reason so it doesn't resurface as a fresh idea next quarter.

## 2. Design opportunities (ranked by impact; each with an honest cost/value call)

### 2.1 Editable brief + re-openable session — **build** — SHIPPED + RECERTIFIED 2026-08-07
- **Voices:** Tomáš: *"vidím, jak se zadání skládá… a chci to opravit, než se
  z toho stane inzerát"* — his file's scored criterion. Priya: *"if the
  comma-splitter mangled my dealbreakers, my only path is a new session."*
  Findings L1-TOM-8 (+ the `correction`-facet ceiling of L1-CONV-2: keyless
  corrections land as a facet, not a field edit).
- **What:** click-to-edit values in the live brief panel (a typed edit is by
  definition `stated`), plus a "reopen" action on a `complete` session that
  flips status back to `open` and appends a system turn. This also retires
  the deterministic parser's fragility (comma-splitting) — the remedy is a
  human edit, not a smarter regex.
- **Cost/value:** ~1–2 sessions of work (panel inputs + one PATCH route +
  status transition + tests). Directly converts the run's biggest trust theme
  ("the one thing I asked it to change…") into UI. **Highest-value open item.**

### 2.2 The defensibility layer: show the grading, trace the turns, export — **build** — SHIPPED + RECERTIFIED 2026-08-07
- **Voice:** Eva: *"Obhájím to před ředitelem? Čím?"* — and L1-EVA-5: weight,
  rationale, confidence exist in the schema but are never rendered;
  `facet.source_turn` has **no writer anywhere**; there is no export of
  brief + transcript for the director meeting. Her felt verdict: *"she'd
  screenshot a chat to defend a weight she can't see."*
- **What:** (a) engine writes `source_turn` on facets/requirements at
  extraction time (the schema slot exists precisely for this); (b) a detail
  affordance in the brief panel exposing weight/rationale/confidence; (c) a
  print/export view (brief + transcript + provenance) — the "hand it to the
  director/inspector" artifact both Eva and Priya described unprompted.
- **Cost/value:** medium (engine one-field change + a panel detail view + a
  print route). The product's differentiator is *defensible* capture; today
  the defense rests on chips + a raw transcript.

### 2.3 Seniority beyond the tech ladder — **build (light)** — SHIPPED + RECERTIFIED 2026-08-07
- **Voice:** Priya: *"I told it Band 5 and it wrote 'medior'. Nobody in my
  building knows what a medior is."* (L1-HRBP-5; the spine-provenance fix
  stops the *lie*, but "Band 5" still has no home.)
- **What:** when a seniority answer matches no enum token, store the verbatim
  answer as a `grade_label` facet (`stated`) and leave the enum `default` —
  the read-back and JD build then carry "Band 5 (grade as stated)" instead of
  silence. Not a taxonomy redesign; a capture-what-they-said fallback.
- **Cost/value:** small; unlocks credibility for every non-tech family the
  100-scenario bank already certifies structurally.

### 2.4 Latency honesty on the thinking bubble — **build (small)** — SHIPPED + RECERTIFIED 2026-08-07
- **Evidence:** L2 measured 31–40 s per exchange behind a static "Přemýšlím…"
  (L2-INT-5, confirming L1-TOM-7). Tomáš: *"60+ s of 'Přemýšlím…' reads as
  hung to an evaluation-anxious first-timer."*
- **What:** elapsed-time hint + one staged copy change after ~20 s ("still
  thinking — long answers take up to a minute"). Explicitly **not** streaming
  (see §2.7).
- **Cost/value:** trivial cost, disproportionate calm for the exact anxious
  segment the register is designed for.

### 2.5 Workspace-context grounding of the dialog — **concept-doc first**
- **Voices:** Tomáš L1-TOM-9 (senior bar: *"a real talent advisor at ČS would
  walk in knowing the team's existing roles, prior JDs, and the market
  band"*); Eva's grounding audit scored the dialog 7/9 with exactly this hole.
- **Why not build directly:** it's a real design problem, not a wiring task —
  which context (existing JDs? Market Pulse band? team roster?), how it
  enters the prompt without bloating 40 s exchanges further, how provenance
  marks agent statements grounded in org data (`inferred` is too weak, a new
  `grounded` value is a schema decision), and privacy scope. Written up as
  the natural Phase-4 concept extension in `docs/concepts/role-intake-dialog.md`'s
  orbit; promote to build once the voice plane (parallel workstream) settles
  the prompt-budget question.

### 2.6 `llm_era_confused` explicit persona clause — **build (one sentence)**
- **Evidence:** L1-TOM-10 (polish): the mode is in the CI bank and handled
  *implicitly* via the 90-day anchor, but no persona clause addresses "do we
  even hire a junior now that we have AI tools?" explicitly.
- **What:** one clause in `_PERSONA_TECHNIQUE`: when the requestor doubts the
  role should exist at all, treat it as a `story` opener and anchor the answer
  in 90-day outcomes ("what would have to get DONE for the hire to be right").
- **Cost/value:** near-zero cost; the L2 probe of this mode then has a rule to
  judge against.

## 3. Methodology lessons (fed into the `/uat drain` mode)

1. **L2's unique catch is emergent model behavior.** The fence-paranoia
   finding (L2-INT-1) was invisible to three careful L1 code readings — the
   defect lived in how the model *interpreted* a correct-looking prompt. Rule
   of thumb now in the skill: on AI-dialog surfaces, L2 is not a rendering
   check, it's the only level that tests the prompt↔model interaction; budget
   it accordingly.
2. **Character voices carry design signal the findings table strips.**
   "Asking for a correction you can't receive is worse than not asking"
   (independently phrased by Tomáš and Priya) became the fix's design
   principle, and 2.1/2.2 came from voice sections, not finding rows. Drain
   must read the voices.
3. **Convergence is a severity signal.** 3/3 Characters independently hitting
   the close-lock outranked any single "major" — the drain ranks convergent
   findings first, before impact arithmetic.
4. **Out-of-segment Characters expose default bias.** Priya (clinical, UK,
   keyless) found the software-engineering default and the tech seniority
   ladder that two tech-side Characters walked past. Roster diversity is not
   fairness theater; it's where default-bias findings come from.
5. **L1 agents should execute, not eyeball.** Eva's agent *ran* the Czech
   regex against inflected phrasings and turned a hunch into a confirmed
   defect with a reproduction. Now an explicit L1 instruction.
6. **L2 doubles as an env-contract regression test.** The run caught the
   server-side `kp_entered` gate drift that had silently invalidated the
   overlay's documented auth path — recorded in `env.md` as part of the run,
   which is exactly where the next session needs it.
7. **Same-day recertify keeps evidence honest.** Fix + `resolved-verified`
   with a fresh screenshot in one session beats a "fixed" label aging in a
   tracker — the loop-closure discipline is now the drain mode's exit
   criterion for `build` items.
